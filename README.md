# John Latif Portfolio

Modern, high-end portfolio website for John Latif - UI/UX Designer & Frontend Developer.

## 🎨 Design Features
- Warm amber, orange, and rich dark gradient color palette
- Split-screen layout with bold typography
- Glassmorphism effects throughout
- Smooth animations and interactive hover effects
- Fully responsive across all devices

## 🛠️ Tech Stack
- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
- Google Fonts (Inter)
- Font Awesome Icons

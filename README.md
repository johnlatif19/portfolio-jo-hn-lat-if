# John Latif Portfolio

Modern, high-end portfolio website for John Latif - UI/UX Designer & Frontend Developer.

## 🎨 Design Features
- Warm amber, orange, and rich dark gradient color palette
- Split-screen layout with bold typography
- Glassmorphism effects throughout
- Smooth animations and interactive hover effects
- Fully responsive across all devices
- Bilingual support (English / Arabic) with RTL layout

## 🛠️ Tech Stack
- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
- Google Fonts (Inter)
- Font Awesome Icons

## 📁 Project Structure
├── index.html # Main HTML structure
├── style.css # Custom styles & animations
├── main.js # Interactivity, scroll effects & language switching
└── README.md # Project documentation

## 🚀 Features

### Sections
- **Hero** – Eye-catching intro with animated background and floating badges
- **About** – Personal bio + core skills & creative technologies
- **Projects** – Showcase of 2 featured projects:
  1. Points System for Dr. Mirna
  2. Login System
- **Skills** – Detailed breakdown of technical & creative skills
- **Contact** – Multiple contact methods (Email, Phone, WhatsApp, Social)

### Interactivity
- Sticky navbar with scroll-based styling
- Mobile hamburger menu
- Smooth scrolling for anchor links
- Fade-in-on-scroll animations (IntersectionObserver)
- Full language toggle (EN ⇄ AR) with automatic RTL support
- Dynamic footer year

## 🌍 Language Support
The site supports **English** and **Arabic**, with automatic direction switching (`ltr` ⇄ `rtl`) and full translation of all UI text via a centralized `translations` object in `main.js`.
